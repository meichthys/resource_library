{# Star rating display, shared by the detail page's rating summary and by each individual review, so a score reads the same wherever it appears. Drawn as two rows of stars, hollow underneath and gold on top, with the gold row clipped to the score. A single element per star can only be on or off, and an average lands between two whole stars more often than not. The rows sit on one line in the markup on purpose: a newline between them would be a text node inside an inline-block, and would widen the row. #} {%- macro star_icon() -%} {%- endmacro -%} {%- macro star_row(max, css_class) -%} {% for i in range(max) %}{{ star_icon() }}{% endfor %} {%- endmacro -%} {%- macro star_rating(value, max=5, size="1em", label=None) -%} {%- set score = value or 0 -%} {%- set caption = label or ("%.1f out of %d stars" % (score, max)) -%} {{ star_row(max, "star-row-empty") }}{{ star_row(max, "star-row-full") }}{{ caption }} {%- endmacro -%}
